# Alpy MCP Overview

Alpy MCP gives your AI agent access to your Alpy Library, web design styles, UI and UX skills, hero structures, components, and design tokens.

### The four tools

| Tool | What it provides |
|---|---|
| `get_alpy_library_index` | Shows what your library contains: available skills, component and token IDs, agent instructions, and React and Vue component previews. Start here to discover what’s available. |
| `get_alpy_skill` | Returns a complete guide for a selected style or design task, its declared dependencies, and up to seven requested supporting references. |
| `get_alpy_components` | Returns component specifications, supported options, and token bindings. Request React or Vue to also receive component code, supporting components, CSS, and declared dependencies. |
| `get_alpy_tokens` | Returns your library’s exact colors, typography, spacing, sizes, border widths, corner radii, and icon dimensions for the selected mode. |

### UI design skills

**UI Design** — Compose a complete interface using the UI principles below.

| Skill | What it helps with |
|---|---|
| Alignment | Establish consistent edges, centers, and text baselines. |
| Balance | Distribute visual weight across the composition. |
| Border and Divider | Clarify boundaries, separation, and states. |
| Color Discipline | Apply colors consistently across roles, states, and modes. |
| Elevation | Communicate depth and relationships between surfaces. |
| Gestalt | Make grouping and relationships immediately understandable. |
| Grid and Layout | Organize regions, columns, spans, and reading order. |
| Motion and Transition | Explain changes, progress, and feedback through purposeful movement. |
| Rhythm and Space | Establish spacing, density, and page pacing. |
| Scale and Proportion | Size content, media, and components appropriately. |
| Typography and Readability | Keep text legible through appropriate type roles, spacing, and wrapping. |
| Visual Hierarchy | Make the order of attention clear. |

### UX design

[Watch Alpy UX explainer video](https://alpymcp.com/ai-taste#ai-taste-user-experience) to see how Alpy UX Skills help you create clearer experiences and easier interactions.

The **User Experience** skill covers these areas:

| Area | What it helps with |
|---|---|
| User-centricity | Define user needs, goals, tasks, and barriers. |
| Usability | Make tasks easy to learn and efficient to complete. |
| Consistency | Keep terminology, patterns, and behavior predictable. |
| Context | Account for users’ circumstances, inputs, interruptions, and constraints. |
| Hierarchy | Prioritize information and actions at each task stage. |
| Navigation and Orientation | Make location, destinations, and next steps clear. |
| Simplicity | Remove unnecessary steps, choices, and content. |
| Cognitive Load | Reduce mental effort and reliance on memory. |
| User Control | Support deliberate choices, cancellation, and reversal. |
| Feedback and Closure | Communicate progress, outcomes, and completion. |
| Error Prevention and Recovery | Prevent mistakes and help users recover without losing work. |
| Readability and Scannability | Make content easy to find, understand, and act on. |

### Hero

The **Hero** skill helps you choose and compose a page’s opening region.

| Structure | Choose it when |
|---|---|
| Centered / stacked | One concise message and action should lead. |
| Split-column | A message and meaningful visual deserve equal presence. |
| Input-capture | Users can begin the main task through search, signup, or another input. |
| Product preview | One real product view best demonstrates the experience. |
| Product showcase | Multiple views, features, or a demonstration explain the product. |
| Full-bleed media | An image or video carries the main story or brand meaning. |
| Carousel | Several equally important messages share one user-controlled region. |
| Editorial / typography-led | Language is the main expressive asset. |
| Illustration / character-led | An illustration or character makes the idea easier to understand or remember. |
| Bento / mosaic | Related capabilities need different visual weight within one overview. |
| Interactive demo | A focused interaction demonstrates the value. |
| Before-and-after / comparison | A truthful comparison makes the transformation visible. |
| Social-proof-led | Verified evidence and testimonials address the main trust barrier. |
| Immersive 3D | An object, space, or spatial experience is central. |
| No hero | Content, navigation, results, or a task should begin immediately. |

### Responsive design and accessibility

| Skill | What it helps with |
|---|---|
| Responsive Adaptation | Adapt an interface to changing space, input, content, language, and user settings while preserving its purpose and behavior. |
| Accessibility Audit | Review an implemented interface for accessibility barriers and report findings with evidence. |

### Design tokens

| Type | What it provides |
|---|---|
| Colors | Values for surfaces, text, borders, icons, and functional states. |
| Typography | Font family, size, weight, line height, and available letter spacing. |
| Measurements | Spacing, sizes, border widths, corner radii, and icon sizes and gaps. |

All four tools are read-only and require **light or dark mode**. Your agent uses the returned guidance, code, and values to carry out the work.
