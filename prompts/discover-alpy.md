# Discover Alpy MCP

Use these prompts with an AI agent connected to Alpy MCP. Select light or dark mode in your chat before requesting library content. The component and token examples below use light mode; change it to dark when needed.

[Read the Alpy MCP Overview](https://alpymcp.com/alpy-mcp-overview/) · [Connect Alpy MCP](https://alpymcp.com/ai-taste#ai-taste-install-title)

## Show the full library index

See what your connected Alpy Library makes available.

> Use Alpy MCP to show the full library index, no summary.

## Explore web design styles

> Use Alpy MCP to explain which web design styles are available in my connected library. Include published prototype links where available.

## Learn about UI and UX guidance

> Use Alpy MCP to explain the UI Design and User Experience skills and when I would use each.

## Explore hero structures

> Use Alpy MCP to show the full Hero skill and explain its available hero structures.

## Inspect a component

> Use Alpy MCP to show the Button component specification and React implementation from my connected library in light mode. Explain its supported options and token bindings.

## Understand my design tokens

> Use Alpy MCP to show my connected library's colors, typography, and spacing in light mode, using the exact token values.

## Learn about responsive design and accessibility

> Use Alpy MCP to explain Responsive Adaptation and Accessibility Audit and when I would use each.

These are starter prompts for discovering features. Your agent reads the current content from your connected Alpy Library through Alpy MCP.
