# Preview locally

From the repository root:

```sh
python3 -m http.server 5174 --bind 127.0.0.1
```

Open [Bento Grid](http://127.0.0.1:5174/prototypes/bento-grid/) or change the folder name to another prototype.

No installation is needed to preview the supplied pages. Some fonts load from Google Fonts. Parallax uses WebGL.

Cyberpunk and Parallax also include source and optional build scripts. Their folder READMEs explain how to rebuild them.
